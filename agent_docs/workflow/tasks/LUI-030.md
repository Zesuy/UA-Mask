## 实施步骤

1. Load status and UCI risk configuration through the reviewed interfaces.
2. Render distinct disabled, starting, running, failed, and anomalous states using text plus semantic LuCI classes, not color alone.
3. Show actual version and active firewall backend.
4. Show current connections, total requests, modifications, pass-through, and cache ratio without a chart library.
5. Show plain-language offload/disconnect risk notices based on saved UCI state.
6. Show a clear route to settings when configuration or enablement needs attention.
7. Poll at five seconds, avoid overlapping requests, preserve a useful last-known view on transient failure, and show a recovery action.
8. Use native LuCI layout/classes, keyboard-accessible links/buttons, and a mobile-first structure with no fixed wide layout.

## 验收标准

- Every required status is visibly and textually distinct.
- Metrics map to existing stats keys and refresh every five seconds.
- Missing stats, adapter failure, and service failure have useful empty/error states.
- Version is not hard-coded.
- No framework, chart, font, or custom visual system is added.
- Page is usable by keyboard and at 375px without horizontal overflow.
