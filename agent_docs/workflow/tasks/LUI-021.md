## 实施步骤

1. Define parent, overview, settings, and diagnostics routes using view actions and stable lowercase route paths.
2. Require a named UA-Mask ACL at the parent route.
3. Grant read/write UCI access only to `UAmask` and exact adapter execution required by product actions.
4. Install the adapter, menu, and ACL in the package.
5. Add `luci-base` while retaining `luci-compat` temporarily because legacy Lua remains; `LUI-060` owns final removal.
6. Add syntax/JSON/route/ACL/package-asset contract scaffolding that can become fully green as pages land.
7. Review the ACL manually for arbitrary command/file access.
8. Record stable route and adapter API decisions before unblocking page tasks.

## 验收标准

- Routes and ACL parse and reflect the confirmed information architecture.
- ACL grants only UCI `UAmask` and exact adapter operations.
- Adapter, menu, and ACL package destinations are correct for OpenWrt 23.05/25.12.
- Legacy Lua remains available until `LUI-060`.
- Page tasks have stable paths and no need to modify shared menu/ACL/package files.

## 风险

- Removing `luci-compat` too early breaks the still-installed legacy route.
- ACL wildcard syntax could grant more than intended.
- Package destinations may differ from source layout.

## 升级条件

- Any required action needs a broader ACL than product security permits.
- OpenWrt 23.05 and 25.12 require incompatible route/ACL layouts.
- Adapter installation introduces a missing unreviewed dependency.

Main resolves and records the decision before page work begins.
