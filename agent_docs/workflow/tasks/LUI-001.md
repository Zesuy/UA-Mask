## 实施步骤

1. Convert the baseline matrix's current behavior into focused shell/Python contracts without changing production code.
2. Add representative legacy scalar fixtures for CSV and space-separated fields.
3. Assert exact JSON schema version, field names, types, defaults, Unicode escaping, safety floors, profiles, and atomic invalid-config preservation.
4. Lock the current procd command, config path, respawn, file trigger, and service action assumptions needed for later lifecycle migration.
5. Wire new focused contracts into `make -C core ci` only when deterministic and host-safe.
6. Run all task validation and report any current behavior that cannot be tested without production changes.

## 验收标准

- Tests fail if a legacy UCI field is silently dropped or remapped.
- Tests cover all scalar list-like formats identified by `LUI-000`.
- Tests remain deterministic and operate only in temporary directories.
- No production implementation changes.
- `make -C core ci` passes on the unchanged implementation.

- Test stubs may mishandle UCI list semantics and create false confidence.
