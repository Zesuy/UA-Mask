1. Create a disposable overlay from the existing OpenWrt 23.05.5 QEMU base.
2. Install the exact package verified in `LUI-061` and its declared dependencies.
3. Execute every QEMU smoke step in `verification.md`.
4. Verify all three pages load without Lua compatibility errors.
5. Exercise a legacy scalar UCI fixture, render, canonical save, JSON equivalence, and single lifecycle action.
6. Exercise controlled disabled, running, invalid configuration, recovery, missing stats/log, and clear-log flows.
7. Verify five-second overview polling without runaway or overlapping requests.
8. Capture 375px viewport evidence, keyboard focus/operation, light/dark theme behavior, and no horizontal overflow.
9. Reboot and confirm service/config/UI recovery.
10. Preserve reproducible evidence in ignored artifacts and summarize it centrally.

Stop and record exact evidence; do not improvise on real infrastructure.
