# LUI-020 — Constrained Status and Diagnostics Adapter

## ID

`LUI-020`

## 目标

Implement one minimal OpenWrt adapter that exposes structured UA-Mask status, runtime version, firewall backend, existing stats, effective configuration, last error, safe log tail, and confirmed log clear without accepting arbitrary paths or commands.

## 实施步骤

1. Define a fixed action surface for status, logs, effective config, last error, version, and clear-log.
2. Read the configured log path internally from UCI; never accept it from browser arguments.
3. Quote all internally resolved paths and reject unknown actions/arguments.
4. Return structured, stable output suitable for LuCI JavaScript parsing.
5. Derive runtime version from the installed binary or package state.
6. Distinguish disabled, starting, running, failed, and anomalous enabled-not-running states using reviewed lifecycle facts.
7. Add isolated temporary-directory tests for successful, empty, missing, denied, and malicious-looking configured path cases.
8. Wire the adapter contract into core shell checks.

## 验收标准

- Adapter exposes only fixed UA-Mask operations.
- Browser callers cannot choose a path, executable, or arbitrary argument.
- Logs are limited to the latest 200 lines.
- Clear-log affects only the internally configured UA-Mask log and reports failure.
- Output distinguishes required product states and includes actual version/backend/stats/effective/error data.
- Tests run without touching real `/var/run`, real logs, services, or firewall.

## 风险

- Shell JSON serialization may be unsafe for Unicode/newlines if not using a structured encoder.
- Process status could race between reads.
- Supporting arbitrary historical log locations could pressure ACL scope; the adapter must keep that path internal.

## 升级条件

- Required status cannot be derived from reviewed stable artifacts.
- A needed init/error path is missing and would require editing a forbidden file.
- Safe structured output requires a new dependency not present on both OpenWrt targets.
- Two attempts fail for the same escaping or isolation issue.

Stop and report the exact interface need to main.
