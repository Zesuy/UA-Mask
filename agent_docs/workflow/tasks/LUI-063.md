## 已确认复现

The exact `LUI-061` IPK installs on disposable OpenWrt 23.05.5 x86/64 and the core service runs, but both fixed adapter actions fail before output:

```text
/usr/libexec/uamask-luci: line 6: JSON_PREFIX: parameter not set
```

The failure occurs while sourcing the platform `/usr/share/libubox/jshn.sh` under `set -u`.

## 实施步骤

1. Establish the minimum initialization required before sourcing OpenWrt 23.05 `jshn.sh`.
2. Preserve `set -u`, every fixed action, argument rejection, path confinement, and structured output contract.
3. Add a host-side regression that fails when the adapter sources a 23.05-compatible jshn stub with `JSON_PREFIX` unset.
4. Run all listed validation without touching QEMU, a host firewall, or central workflow files.
