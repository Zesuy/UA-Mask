## 实施步骤

1. Review every page diff and confirm no worker changed unauthorized files.
2. Resolve page/shared-interface integration centrally.
3. Make all route-to-view, JavaScript syntax, ACL, adapter, and package-asset checks mandatory.
4. Confirm existing UCI loads and Save & Apply uses the single reviewed lifecycle.
5. Confirm package installation contains all JavaScript and adapter assets.
6. Only after all previous checks pass, delete the two legacy Lua files.
7. Remove their installation rules and remove `luci-compat`, retaining minimal `luci-base` and required runtime dependencies.
8. Verify no source, package, menu, or documentation reference still requires the removed Lua path.

## 风险

- Package routes can appear correct in source but install to incorrect destinations.
- A hidden Lua compatibility dependency may remain.
- Integrating page feedback may duplicate lifecycle actions.

## 升级条件

- Any replacement page or contract is not green.
- Package dependency resolution differs between supported OpenWrt versions.
- Removing Lua would make any route unavailable.
- A compatibility issue needs changes outside the allowlist.

Do not delete Lua; record the blocker and create a focused task.
